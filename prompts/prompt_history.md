# תיעוד הנדסת פרומפטים ושיח מול המודל (LLM Prompt Engineering Log)

מסמך זה מתעד את תהליך ההנחיה, הבקרה והדיוק ההנדסי שבוצע מול מודל השפה (LLM) לאורך מחזור החיים של פרויקט "חיפה מחדש".

---

## שלב 1: איפיון ודרישות מוצר (PRD & Architecture)
* **מטרה:** הגדרת חזון הקמפיין, קהלי היעד, ערוצי השיווק ומבנה הפרויקט הטכנולוגי.
* **הנחיה למודל (Prompt):**
  > "בנה מסמך PRD מקיף לפרויקט מיתוג עירוני רב-ערוצי לעיר חיפה בשם 'חיפה מחדש'. הדגש את שילובן של שלוש שכבות: מצגת אינטראקטיבית ב-HTML5/CSS3, מנוע אנליטי ב-Python לחישוב מדדי ביצוע (KPIs) ותקציב, ומסגרת להדמיית מרחב עירוני בתלת-ממד. הגדר ארכיטקטורת קבצים מלאה."
* **בקרת איכות ותוצר:** נוצר קובץ `PRD.md` המפרט את יעדי הקמפיין (250,000 ₪ תקציב, יעדי חשיפה והמרות), חלוקת השקפים ומבנה התיקיות.

---

## שלב 2: פיתוח המצגת הדיגיטלית (`index.html`)
* **מטרה:** יצירת ממשק מצגת מודרני, מותאם לעברית (RTL) עם ניווט מקלדת.
* **הנחיה למודל (Prompt):**
  > "כתוב קובץ index.html עצמאי הכולל מצגת אינטראקטיבית מעוצבת ב-Dark Theme (פלטת כחול עמוק, טורקיז וטקסט בהיר). המצגת תכלול 3 שקפים: שער המותג וקהל היעד, מסגרת ייעודית להדמיית 3D, ושקף אנליטיקה המציג את נתוני ה-Python. הוסף תמיכה מלאה במקשי חיצים למעבר שקפים, מונה שקפים דינמי, ועימוד responsive."
* **בקרת איכות ותוצר:** הממשק נבדק בדפדפן; נבדק דיוק ה-RTL ותקינות מעבר השקפים.

---

## שלב 3: מנוע נתונים ואוטומציה ב-Python (`main.py`)
* **מטרה:** פיתוח סקריפט Python שמחשב KPIs, מייצא גרפים ומפעיל את המצגת.
* **הנחיה למודל (Prompt):**
  > "צור סקריפט Python בשם main.py שמבצע הדמיה תקציבית לקמפיין שיווק (250,000 ₪) ומחלק אותו לערוצים דיגיטליים, אירועים ופרסום חוצות. חשב חשיפה ופניות (Leads). צור תרשים ויזואלי באמצעות Matplotlib (עוגה ועמודות מותאמים לצבעי המצגת) ושמור אותו כ-campaign_analytics_chart.png. בנוסף, ייצא את הנתונים ל-campaign_metrics.json ופתח את index.html בדפדפן בסיום."
* **בקרת שגיאות:** 
  - טיפול בשגיאת `ModuleNotFoundError: No module named 'matplotlib'` בסביבת Python 3.14 ע"י התקנה מדויקת דרך מודול הפייתון.
  - הפרדה מלאה בין קוד הפייתון ל-HTML למניעת שגיאות SyntaxError.
